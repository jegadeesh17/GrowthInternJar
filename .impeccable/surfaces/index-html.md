# Dashboard (index.html)

Scope: single-file assignment dashboard. Mode: Operate (reviewers scan KPIs, then drill into Q1/Q2/Q3/Methodology).
Audience: Jar hiring reviewers on desktop, daytime. Constraints: dashboard-data JSON block untouched; no build step; Chart.js via CDN.

## Direction contract
THESIS: A Minimal-UI-Kit-grade analytics console in pastel. It refuses the stacked top-tab template with bordered KPI tiles and saturated chart colours.
OWN-WORLD: Kit grammar: a white left sidebar with a tinted active pill and Q-number labels, a blurred sticky top bar, white 16px cards with the two-layer kit shadow, grey 100–800 ramp. Pastel roles: lavender (primary), mint, butter, peach, sky. Tints fill surfaces and the darker shade of each hue carries text. Soft Label chips, sentence-case table heads on a grey-200 band, dashed chart grids. DM Sans body, Barlow headings.
STORY: A reviewer sees four headline numbers, reads the findings timeline, then jumps straight into any question from the shortcut cards or the sidebar.
FIRST VIEWPORT: Sidebar left (brand, 5 nav items). Main: page title, a row of 4 tinted stat widgets (the furniture one has a monthly sparkline), then an 8/4 row of findings timeline + category-mix doughnut.
FORM: pinned by user brief (Minimal UI Kit + pastel); roll skipped because a pinned brief beats the roll. Seed key: none (pinned). Signature interaction: section switch with a soft rise-and-fade; mobile sidebar becomes a drawer.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
